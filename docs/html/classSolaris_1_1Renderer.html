Detailed Description

Solaris Renderer class.

Almost all interactions with OpenGL will be done through this class. A sort of an OpenGL wrapper, if you will.

◆ AttachShader()

void Solaris::Renderer::AttachShader ( Shader & shader)

Attach a new shader to the current renderer.

Note
Please note that when attaching a shader to a renderer, the attached shader will be copied to a new location. Hence its a good idea to discard of the shader after it has been attached, unless you plan on using it elsewhere later.
Bug
When attaching a shader to a renderer with an already attached shader, the previous shader won't be deallocated on the memory.
Parameters
shaderShader object to be attached.
