Resource Management

Resources and resource management are both very crucial components of Solaris. You will encounter a lot of Solaris components which you'll need to assign resource(s) to for them to function properly.

Resources

A resource is any memory block which Solaris does not explicitly define its size. Some of the things that fall in this category are: texture data, mesh data, an array of integers, shader source code, etc. to name a few.

To define a resource in Solaris, you must use the Resource or CastedResource type. The difference between these two resource types will be explained further on.

#include <ResourceMan/ResourceMan.hpp>
int arr[] = { 0, 1, 2, 3, 4, 5 };
Resource foo = {
.size = sizeof(arr), // size of the resource in bytes
.pdata = (void*)arr // a void pointer to the beginning of the resource
};
char some_cstring[] = "Hello World!";
CastedResource<char> bar = {
.len = sizeof(some_cstring) / sizeof(char), // number of `char' elements in this resource
.pdata = some_cstring // a `char*' pointer to the beginning of the
// resource (no casting needed here)
};

The Resource Type

The Resource type is conventionally used for resources with unspecified data types, or as a generic resource type. Most Solaris functions will expect a resource with a known data type (e.g., the Model render object expects a CastedResource<float> as its mesh data, and CastedResource<unsigned char> as its texture). As such, one could say that the Resource type acts mostly as an intermediary type.

The CastedResource Type

The CastedResource type is used for resources with known data types. CastedResource accepts a typename template parameter, the value of which is used to determine the pointer type of the resource.

The two key differences between a CastedResource and a Resource is that, first, unlike the Resource type, CastedResource isn't necessarily supposed to hold a void pointer to the resource; rather, it is up to the programmer to specify what type of resource the CastedResource is pointing to; and second, instead of a size property, CastedResource holds a len property which determines how many values the resource is holding. i.e., assuming the resource is an array, len is how many elements the array is holding

Casting Resources

Consider the following example of manually casting a Resource to a CastedResource<int>.

Attention
It's not recommended and heavily discouraged to manually cast a Resource type. Instead, one must use the CastResource function to do so, which will be expanded upon later.
#include <ResourceMan/ResourceMan.hpp>
int data[] = { 0, 1, 2, 3, 4, 5 };
Resource uncasted = {
.size = sizeof(data),
.pdata = (void*)data
};
CastedResource<int> casted = {
.len = uncasted.size / sizeof(int), // get the # of elements in array
.pdata = data // no need for casting -- resource is already
// of the expected type
};

As specified above, this is a highly discouraged practice. One must instead use Solaris's own casting function, CastResource:

...
CastedResource<int> casted = CastResource<int>(uncasted);

In the example above, we used the previously-defined resource uncasted, but instead of casting it manually, we used the CastResource function. CastResource accepts a single typename template parameter, a single Resource parameter , and returns a CastedResource casted to the specified typename.
