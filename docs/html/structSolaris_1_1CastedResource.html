Detailed Description

template<typename _data_type>
struct Solaris::CastedResource< _data_type >

Holds information about a specific resource with known data type.

Same as Resource except for resources with known data types.

Template Parameters
_data_typeTypename of the resource's data.
Attention
The _data_type template parameter is the type of the data the CastedResource points to, not the type of the pointer itself (e.g. if you have an array of unsigned chars, its appropriate CastedResource pointing to said array would be CastedResource<unsigned char>, not CastedResource<unsigned char*>)
