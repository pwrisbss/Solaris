Detailed Description

Solaris Shader Class.

Solaris's C++ wrapper for the OpenGL shader system. Each Shader object represents an OpenGL shader pipeline (currently only supports one vertex shader and one fragment shader).

unsigned Solaris::Shader::GetShaderProg ( )

Get the shader program ID.
