template<typename _cast_type>
CastedResource< _cast_type > Solaris::CastResource ( Resource & resource)

Casts a Resource object to a CastedResource<_cast_type>.

Conventionally, a Resource object points to a resource whom its data type is unknown. Mainly, it only exists so that a resource manager can store, process and manage resources of any type. As such, most Solaris components will ask for resources with known data types. See Resource Management.
