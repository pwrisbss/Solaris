A Render Object is defined as an object that can be pointed to by a {\ttfamily \doxylink{classSolaris_1_1RenderObject}{Solaris::\+\+Render\+Object}\texorpdfstring{$\ast$}{*}}. Basically, what this means is that any object of any class that derives from {\ttfamily \doxylink{classSolaris_1_1RenderObject}{Solaris::\+\+Render\+Object}}, along with {\ttfamily \doxylink{classSolaris_1_1RenderObject}{Solaris::\+\+Render\+Object}} itself, could be considered a Render Object.

\hypertarget{renderobject_renderobject-definition-siblings}{}\doxysubsection{\texorpdfstring{Relationship with Siblings}{Relationship with Siblings}}\label{renderobject_renderobject-definition-siblings}
Along with the aforementioned requirement, a render object must have at least one state/\+configuration which allows all of its siblings (render objects attached to the same renderer, see \doxysectlink{renderer}{The Solaris Renderer}{0}) to function normally even when itself is present.

In other words, consider a render object type such as {\ttfamily \doxylink{classSolaris_1_1Model}{Solaris::\+\+Model}}. Its possible configurations are all the mesh and texture resources ({\ttfamily \doxylink{structSolaris_1_1Resource}{Solaris::\+\+Resource}}), positions, rotations, etc. it can contain. Normally, every model configured in a certain way could be siblings with all the other models configured in different ways, without causing any of them to render improperly.

Alternatively, consider a render object type such as {\ttfamily \doxylink{classSolaris_1_1Camera}{Solaris::\+\+Camera}}. Its possible configurations are the different possible positions, projections, etc. it can have (plus an enabled/\+disabled state). While an enabled {\ttfamily \doxylink{classSolaris_1_1Camera}{Camera}} object would cause problems if siblings with other enabled {\ttfamily \doxylink{classSolaris_1_1Camera}{Camera}} object(s), in its disabled configurations, it doesn\textquotesingle{}t cause any problems with rendering or any other events (unless its somehow misconfigured otherwise).
