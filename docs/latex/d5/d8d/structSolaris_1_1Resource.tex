\doxysubsection{Detailed Description}
Holds information about a specific resource. 

In other words, an object of type \doxylink{structSolaris_1_1Resource}{Resource} is a vector pointing to a memory block (that is, the size of the memory block and a pointer to the start of said memory block). Comparing \doxylink{structSolaris_1_1Resource}{Resource} objects are supported.
